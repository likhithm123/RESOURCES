# UPSC - From Zero to IAS & Preparation Portal

Handwritten-style comprehensive notebooks for the complete UPSC Civil Services Examination (IAS) syllabus plus a synchronized progress-tracker portal with Admin CMS, day-wise streaks, and sign-in history.

## Features
- **Comprehensive UPSC Notes:** Handwritten-style notebooks with foundational concept-building from zero level, diagrams, mnemonics, and previous years' questions (PYQs Prelims & Mains).
- **Track Sheet & Day-Wise Streaks:** Real-time syllabus tracker tracking completion percentage and daily study streaks.
- **Admin CMS:** Manage documents, team members ("Brought to you by"), user progress, contact details, and audit logs.
- **Database:** Cloudflare D1 database (`resources` - `3382b9ae-0c09-43f6-ab69-5a22503314cf`).
- **File Storage:** Private ImageKit storage.
