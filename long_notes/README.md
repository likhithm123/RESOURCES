# Long-Form Deep-Dive Master Editions (100–250+ Pages Curriculum)

This directory is the dedicated home for **Long-Form Comprehensive Notes**, kept strictly separate from the concise handwritten quick revision notes in `notes/content/`.

---

## Architecture: Short Notes vs Long-Form Master Editions

| Aspect | Short Notes (`notes/content/`) | Long-Form Editions (`long_notes/`) |
|---|---|---|
| **Target Audience** | 24-hour rapid interview recap & quick formula reference | In-depth foundational mastery (from absolute beginner to principal level) |
| **Typical Length** | 5 – 40 pages per topic | 100 – 250+ pages per subject track |
| **Code Style** | High-density core snippets and key algorithmic patterns | Full end-to-end runnable code with step-by-step trace comments, edge cases & outputs |
| **Visual Architecture** | Compact `@flow` and `@layers` sketches | Full ASCII/SVG multi-tier architectural diagrams, state machine transitions, and memory layouts |
| **Analogies** | 1-line real-life analogies per concept | Extended story-based real-life narrative scenarios (e.g., complete restaurant kitchen walkthroughs, hotel management hierarchies) |
| **Complexity Analysis** | Summary Big-O tables | Formal mathematical proofs, recurrence relations, and amortized time/space complexity derivations |
